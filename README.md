为 Foundry VTT 的 **Starfinder 2e** (`sf2e`) 系统主体提供中文翻译。

> 抢先体验阶段。许多 UUID 重映射尚未完成（相比成熟的 PF2e 翻译），术语表大量借鉴 PF2e 中文化组的成果。

## 内容 / Contents

- `zh_Hans/zh_Hans.json` — 系统主体（i18n key → 中文）
- `zh_Hans/action-zh_Hans.json` — 动作元素
- `zh_Hans/kingmaker-zh_Hans.json` — 拥王者元素
- `zh_Hans/re-zh_Hans.json` — 规则元素

## 安装 / Install

在 Foundry → **附加模块 → 安装模块** 中粘贴 manifest URL：

```
https://github.com/takaqiao/sf2e_cn/releases/latest/download/module.json
```

或在 Foundry 包浏览器搜索 `sf2cn`。

## 依赖 / Requires

- Foundry VTT v12 ~ v14
- Starfinder Second Edition (`sf2e`) 系统
